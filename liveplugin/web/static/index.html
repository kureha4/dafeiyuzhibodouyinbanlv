关键：先开 F12 再刷新页面，WS 连接只在页面加载时建立一次。
① 无痕窗口打开直播间 → 按 F12 → 切到「网络」标签 → 按 Ctrl+R 刷新页面
② 在「过滤」输入框直接输入 im/push（比点 WS 按钮更稳）
③ 等 5~10 秒播放器起来，会出现一条类型为 socket 的行，名字是 v2/?app=10013…
④ 点开它 → 右侧「标头」→ 最上面「请求 URL」→ 右键 → 复制值
⑤ 粘贴到上面输入框，点自动解析。
凭据保存到 config.json（明文，谨慎）

背景抠像（绿幕/纯色背景）
普通视频（如手机拍的 mp4）背景是绿幕/纯色时：勾上「背景抠像」、把颜色选成背景色，就会自动抠成透明，效果等同透明素材。透明视频自带 Alpha，无需抠像。上传后存为 assets/character.* 并即时生效。
